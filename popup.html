⚙️ Settings

📋 Instructions

1. Create a new integration at notion.so/my-integrations

2. Copy the integration token and paste it above

3. Create a new database in Notion with these properties:

  • Job Title (Title)
  • Company (Text)
  • Location (Text)
  • URL (URL)
  • Date Applied (Date)
  • Status (Select: Applied, Interview, etc.)
  • Description (Text)

4. Share the database with your integration

5. Copy the database ID from the URL and paste it above

🚀 How to Use

Navigate to a job posting on LinkedIn, Indeed, Glassdoor, or other supported sites. Click the "Save to Notion" button that appears on the page.
